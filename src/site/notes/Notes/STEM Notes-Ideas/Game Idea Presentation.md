# VEX Game

Ideas
 - Refresh points after `x` amount of tasks
 - Don’t last forever
 - Press a button
 - Flip a switch 
 - Move block from `x` to `y`
 

Task Ideas
- Easy Tasks
	- Button Press (2its)
	- Switch Flip (2its)
	- Move Block/Crate (3-4its)
- Harder Tasks
	- Operation
		- Its just operation
	- Art Block
		- Build Pic with Scattered Events
