# THESIS

# KEY POINT \#1

Now, I get it, one thing a day is quite a bit, but it doesn't have to be something huge, like how to write a book; or how to start a business; it could be something small, like a fun fact about an interest you have, or a cool craft.  You could even re-learn something you've forgotten, like how to skip, or how to imagine the impossible. 

# KEY POINT \#2

You don't need to have someone who knows these things to teach you, you could go to the library and find a book on how to do it, look it up, or even watch a video on social media. If you want to learn something that requires tools, some libraries have makerspaces, where you can get time on things like power tools, 3d printers, and laser engravers
